# Code Availability

The complete reference implementation for the AAO-MARN experimental pipeline is provided in this repository. It contains the data-preparation procedure, binary class-mapping logic, preprocessing and segmentation stages, VGG16 feature extraction, GOA-based feature selection, multi-head attention, recurrent spatial-context modelling, Artificial Algae Optimization, ablation analysis, calibration evaluation, statistical testing, complexity analysis, modern baseline benchmarking, and external-validation utilities.
